# Specialized AI Agents Registry

This document lists the cognitive responsibilities of each agent.

## Core Agents
- **Mission Planner**: Interprets goals, determines the required execution steps, and records tasks.
- **Knowledge Agent**: Connects to the database and converts queries to vector representations.
- **Ingestion Agent**: Splits resume texts into clean semantic segments and requests embedding vectors.
- **Filter Agent**: Identifies semantically matching candidates.
- **Ranking Agent**: Computes compatibility scores (0-100) for candidates.
- **Email Agent**: Generates drafts and sends emails via Gmail API.
- **Calendar Agent**: Schedules meetings and generates Meet links.
- **Report Agent**: Generates summary recruitment documents.
